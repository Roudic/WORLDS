# Project Riftwake — Visual Style Guide

Reference pack for art direction on the Crossfall Trials vertical slice.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Night slate | `#0A1018` | World void, UI base |
| Deep navy | `#121C2A` | Panels, interiors |
| Flux mint | `#6EE7C5` | Pulse/Lumen hybrid UI, controlled power |
| Amber wake | `#F0A35E` | Pressure, rivals, lantern warmth |
| Ink | `#E8EEF6` | Primary text |
| Mute steel | `#8FA3B8` | Secondary text |

Avoid: purple-on-white gradients, cream/terracotta editorial looks, hair-color power-ups, recolored franchise silhouettes.

## Flux visual language

| Form | Behavior | Color / material |
| --- | --- | --- |
| **Pulse** | Dense, body-bound impact | Copper-amber, heat shimmer, breath rhythm |
| **Aether** | Living environmental flow | Teal-green vines, storm filaments |

## Silhouette rules

1. Ascensions change geometry, materials, and body language — never just hair color or a borrowed pose.
2. Ironwoken read as persons with modular craft, not robots-as-props.
3. Crossfall architecture always shows at least two joined realities in one frame (stone + neon, forest + hull, temple + machine).
4. Combat FX should telegraph Flux type before raw brightness.

## Motion notes (UI / cinematics)

- Slow parallax drift on hub skies
- Clash: three-beat compression (push / flash / resolve)
- Rift overlays: brief double-exposure, not constant shake
